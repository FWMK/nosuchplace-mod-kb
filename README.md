非官方知识库，用于集中说明「查无此地（NoSuchPlace）」MOD 整合包的内容、安装方式与常见问题。适合玩家查阅，也适合接入聊天机器人的外置知识库（RAG）检索。

## 内容覆盖

- 整合包概览：版本、适用游戏、双 BepInEx 前置、部署特性
- 9 个 MOD：词缀选择器、更多自定义配置、伤害数字与血条、蹊径 · 黑市、MOD 调校终端、寻物地图、安全屋便捷设施、手雷破门、高维凝视
- 安装、更新、切栈、选择性安装、备份回滚、命令行参数
- 默认热键总表（含热键冲突提示）
- 13 条常见问题（SmartScreen 拦截、找不到游戏、游戏运行中拒绝部署、同版本不覆盖、应愿粉尘获取等）

## 接入机器人知识库

以 AstrBot 为例，可直接把本仓库的 Markdown 文件加入知识库：

1. 人工上传：[docs/查无此地MOD整合包_知识库.md](docs/查无此地MOD整合包_知识库.md)
2. 或使用 Raw 链接抓取：
   `https://raw.githubusercontent.com/<你的用户名>/nosuchplace-mod-kb/main/docs/查无此地MOD整合包_知识库.md`
3. 建议分块大小 500～800 字，按 Markdown 标题切分。

## 更新约定

- 文档内容随整合包版本更新，版本号在文档「一、整合包概览」与「八、版本记录」中标注。
- 新增 MOD 或热键变更时，同步更新「二、MOD 清单」与「四、MOD 手册」「4.0 默认热键一览」。
