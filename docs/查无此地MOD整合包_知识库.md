# 查无此地 MOD 整合包 · 知识库

> 用途：AstrBot 外置知识库。本文档描述「查无此地（NoSuchPlace）」MOD 整合包 v1.0.1 的安装方式、功能与常见问题。
> 数据来源：整合包清单、部署器源码、各 MOD 源码。文中版本号与热键均为包内实际值。

---

## 一、整合包概览

- 名称：查无此地 MOD 整合包
- 版本：整合包 v1.0.1（部署器程序内部版本 1.0.0，界面标题栏显示为 v1.0.0，信息栏显示包版本 v1.0.1）
- 适用游戏：查无此地 NoSuchPlace（Unity 引擎，游戏版本 6000.3.23f1，Windows x64）
- 文件形态：单文件自包含 exe，双击运行，无需解压，无需安装 .NET
- 包体积：约 1.82 MB
- 前置：包内自带两套完整隔离的 BepInEx —— BepInEx 5.4.23.5 与 BepInEx 6（build 788）
- MOD 数量：9 个（两套前置各一份对应构建，共 18 份插件文件）
- 部署特性：自动定位游戏目录、自动识别前置栈、增量部署（SHA256 比对）、自动备份与回滚、MOD 配置合并、可选装（勾选式）

整合包只包含以下 9 个 MOD，不含其它第三方插件。

## 三、安装与部署

### 3.1 安装步骤

1. 完全退出游戏（部署器检测到游戏进程会拒绝部署）。
2. 双击整合包 exe。部署器会按顺序自动寻找游戏目录：exe 同目录 → Steam 库 → 手动选择。
3. 部署器自动识别目标机已安装的前置是 BepInEx 5 还是 BepInEx 6，并只部署对应栈的 MOD。
4. 若目标机没有任何前置，界面会要求选择 5 或 6；命令行必须显式指定 `--stack 5` 或 `--stack 6`。
5. 在 MOD 清单中勾选要安装的 MOD，点「开始部署」。
6. 部署完成后可直接启动游戏。

选择游戏目录时，要选到游戏根目录（含 `NoSuchPlace.exe` 的那一层），不是上一级目录。选错层级会导致检测不到已装前置。

### 3.2 状态列含义

清单的「状态」列只有三种：

| 状态 | 颜色 | 默认勾选 | 含义 |
|---|---|---|---|
| 待安装 | 红色 | 勾选 | 本机尚未安装该 MOD |
| 有更新 | 绿色 | 勾选 | 本机已装，但包内版本更高 |
| 同版本 | 黑色 | 不勾选 | 本机已装且版本与包内一致，可跳过 |

- 判断依据只有版本号，不比较文件内容。若某 MOD 版本号未变但内容有修正，需要该 MOD 提升版本号才会被判为「有更新」。
- 未勾选的已装 MOD：文件与配置全部保留，不会被覆盖或删除。
- 清单上方的「全选」复选框位于「安装」列正上方，可一键全选或取消全部。

### 3.3 切换前置栈

从 BepInEx 5 切到 6（或反向）时：

- 旧栈的 core 与插件会先备份再清理，避免 5/6 混装。
- 清单会全部标记为「待安装」并默认全选，因为 MOD 与前置栈绑定，必须整套重装。
- 清单下方出现橙色切栈提示，部署确认框会再次提醒。
- 未勾选的旧栈插件会被保留，可能与新栈不兼容；干净切换请保持全选。

### 3.4 备份、回滚与状态文件

- 备份与状态目录：游戏根目录下的 `.nosuchplace\`
- 备份位置：`.nosuchplace\backups\<时间戳>\`
- 状态文件：`.nosuchplace\state.json`（记录已装栈、版本与文件清单）
- 新建文件记录：`_created.txt`（回滚时用于删除本次新建的文件并清理空目录）
- 日志：`.nosuchplace\logs\`
- 回滚：命令行加 `--rollback` 可还原最近一次部署前的状态

部署采用增量策略：只写入 SHA256 不同的文件，未变化的文件保持原样；被覆盖的文件先备份。

### 3.5 命令行参数

| 参数 | 作用 |
|---|---|
| `--stack 5\|6\|auto` | 指定或自动识别前置栈 |
| `--target <目录>` | 指定游戏根目录 |
| `--only <目录,…>` | 只安装列出的 MOD 目录，未列出的已装 MOD 保持原状 |
| `--dry-run` | 只比对差异，不写磁盘 |
| `--rollback` | 回滚最近一次备份 |
| `--no-launch` | 部署后不启动游戏 |
| `--report <json>` | 输出机器可读的部署报告 |
| `--help` | 查看帮助 |

### 3.6 部署约束

- 部署前必须完全退出游戏。
- 不覆盖 `BepInEx.cfg`，不修改游戏存档。
- 部署器只管理自己清单内的 MOD 文件；不清理清单外的其它插件。
- 若目标机存在 5/6 混装插件，部署时会按所选栈备份并清理**已勾选 MOD** 的另一栈文件，不会残留另一栈的 framework。
- 安装文件被 Windows 标记为「来自网络」（MOTW）时，首次运行会弹 SmartScreen「未知发布者」；可右键 exe → 属性 → 勾选「解除锁定」后确定。

## 四、MOD 手册

### 4.0 默认热键一览

| 热键 | 归属 MOD | 作用 |
|---|---|---|
| F5 | 更多自定义配置 | 打开调校面板 |
| F6 | 伤害数字与血条 | 打开设置窗口 |
| F6 | 查无此地 · 寻物地图 | 打开/关闭地图 |
| F7 | MOD 调校终端 | 唤出/关闭统一调校面板 |
| F7 | 查无此地 · 寻物地图 | 清除当前追踪目标 |
| F8 | 伤害数字与血条 | 开关敌人血条 |
| F9 | 伤害数字与血条 | 开关伤害数字 |
| F10 | 伤害数字与血条 | 开关战斗统计面板 |
| 按住 CapsLock | 高维凝视 | 显示/隐藏物品标签（可改切换式） |
| L + Ctrl + Shift | 高维凝视 | 打开物品过滤配置窗口 |

注意：**F6 与 F7 在包内存在默认热键重叠**（伤害数字设置窗口 vs 寻物地图；调校终端 vs 寻物地图清除目标）。实际触发顺序由插件加载顺序决定，可能与预期不符。建议在对应 MOD 的 cfg 中把其中一方改成其它按键，避免误触。

### 4.1 词缀选择器（AffixSelectorMod 2.0.1）

- 功能：在反应堆强化（Reactor Enhancer）界面中选择想要的词缀，而不是随机获得。
- 交互：打开反应堆强化面板后，按面板提示选择词缀组或单条 DIY 组合；界面会显示最大选择数、当前消耗与槽内应愿粉尘数量。
- 消耗：自选词条消耗「应愿粉尘」。界面提示形如「应愿粉尘：自选词条时消耗」「需要 X / 槽内 Y」。
- 应愿粉尘来源：
  - 制作台（General 工作台）配方：产物 1 个；材料为 `material_contagionTrash`×99、`material_RDPowder`×15、`consume_PoppingCandy`×99（材料中文名以游戏界面为准）。
  - 黑市购买：单价 50000，稀有度 1，单格堆叠上限 3。
- 注意：应愿粉尘的物品与配方由该 MOD 在游戏静态数据加载时注入，属于「MOD 新增内容」，不是游戏原生物品。

### 4.2 更多自定义配置（NoSuchPlace.CustomWeight 1.10.0）

- 功能：对角色数值与成长曲线做深度调校，含负重、移动速度、子弹堆叠、经验倍率、等级上限、能力上限、天赋门槛等。
- 热键：`F5` 打开调校面板。
- 主要配置分组（配置文件 `com.deepseek.nosuchplace.customweight.cfg`）：
  - 常规：启用、负重上限、负重模式（覆盖 / 固定 / 追加）、移动速度、速度模式、生效间隔（默认 0.5 秒轮询校正）
  - 子弹堆叠：启用、倍率规则
  - 经验倍数：启用、角色经验倍率、技能经验倍率、倍率规则、突破等级上限、等级上限、7 级后基础经验（默认 26000）、每级增长（默认 1.4）
  - 能力上限：突破能力上限、能力等级上限
- 补充：也可以在 MOD 调校终端（F7）的「更多自定义配置」专用页里调，两种入口改的是同一份配置。

### 4.3 伤害数字与血条（DamageNumbersMod 1.3.6）

- 功能：命中时显示浮动伤害数字，给敌人显示血条，并提供战斗统计面板。
- 热键：`F6` 设置窗口、`F8` 开关血条、`F9` 开关伤害数字、`F10` 开关统计面板。
- 配置分组：伤害数字、生命条、统计、热键、调试。
- 适合希望直观看到伤害与敌人剩余生命的玩家。

### 4.4 蹊径 · 黑市（NoSuchPlace.Shop 0.3.2）

- 功能：替换/增强黑市界面，商品分页显示、可搜索筛选，避免一次性渲染大量商品造成卡顿。
- 默认行为：分页开启，每页 20 件。
- 主要配置分组：定价、商品目录、交易、调试、分页。
- 「仅官方物品」默认开启：只展示游戏原生可获得的物品（掉落组内、掉率大于 0 的物品）。MOD 新增物品若不在官方可获得集合内会被过滤，需要时可在 cfg 中关闭该开关后重启游戏。
- 支持导出商品目录为 CSV（用于核对物品 key 与价格）。
- 注意：黑市商品目录在进入黑市时构建并缓存；刚新增/更新的 MOD 物品需要重进游戏或重新打开黑市才会出现。

### 4.5 MOD 调校终端（NoSuchPlace.TerminalTuner 1.4.0）

- 游戏中显示名为「MOD调校」。
- 功能：游戏内统一面板，集中查看并修改各 MOD 的配置项，支持按插件、分节、键名检索；部分插件提供专用页（结构化的图形界面）。
- 热键：`F7` 唤出/关闭。
- 入口：游戏菜单中的「MOD调校」。
- 常用配置（`com.fengwenmoke.nosuchplace.terminaltuner.cfg`）：唤出热键、菜单入口开关、入口文字、界面缩放（默认 1.0）、背景压暗（默认 0.55）。
- 专用页机制：宿主只提供通用参数行；「更多自定义配置」的专用页由同目录的扩展 DLL 提供。扩展缺失或协议版本不匹配时，该插件自动回退为通用参数行并在日志中提示一次，不影响其它功能。
- 显示层汉化：面板会把他人的英文插件名、分节、键名映射成中文显示，但只影响显示与检索，不修改对方 cfg 里的真实键名。

### 4.6 查无此地 · 寻物地图（NoSuchPlaceAtlas 0.3.2）

- 功能：在游戏地图中查询并追踪指定物品/目标的位置。
- 热键：`F6` 打开/关闭地图面板，`F7` 清除当前目标。
- 扫描节奏：面板打开时全量扫描间隔 3 秒；面板关闭时追踪间隔 0.5 秒。
- 主窗口尺寸 1120×710。
- 注意：需在进入地图后使用；面板内会提示「进入地图后可查询」。

### 4.7 安全屋便捷设施（SafeHouseAccessMod 1.1.1）

- 功能：在安全屋内提供便捷设施：快捷存取背包、挂墙储物、保险箱，并启用远程制作与快速堆叠；可配置过滤规则与聊天提示。
- 适合频繁整理物资的玩家。

### 4.8 手雷破门（NoSuchPlace_GrenadeDoor 1.8.0）

- 游戏中显示名为 Grenade Door Breach。
- 功能：用手雷炸开上锁的门。
- 配置：启用（默认开）、炸门难度（默认 easy，可选 easy / normal / hard，对应不同手雷数量范围）。

### 4.9 高维凝视（NoSuchPlace_ItemLabel 2.0.0）

- 功能：按住按键时，在屏幕上为可见物品、容器、搜点、尸体叠加文字标签，显示名称、数量、按售价分色等信息。
- 热键：
  - 默认按住 `CapsLock` 显示/隐藏标签（模式可改为切换式）。
  - `L + Ctrl + Shift` 打开物品过滤配置窗口。
- 配置要点：默认显示开启、字体大小 20、按键模式默认 Hold、任务所需物品红色光柱默认开启。
- 物品过滤：`item_filter.txt` 可配置隐藏/显示列表；配置窗口内也可按分类勾选，支持搜索、全选/全不选、保存与关闭。
- 与调校终端联动：其配置项在调校终端内以中文显示，可直接在终端内修改。

## 五、目录结构

```
游戏根目录\
├─ NoSuchPlace.exe
├─ winhttp.dll                      ← BepInEx 注入入口
├─ BepInEx\
│  ├─ core\                         ← 前置本体（5 或 6）
│  ├─ plugins\
│  │  ├─ AffixSelectorMod\
│  │  ├─ NoSuchPlace.CustomWeight\
│  │  ├─ DamageNumbersMod\
│  │  ├─ NoSuchPlace.Shop\
│  │  ├─ NoSuchPlace.TerminalTuner\   ← 含 TerminalTuner.dll、TunerSdk.dll、CustomWeight.TunerExt.dll
│  │  ├─ NoSuchPlaceAtlas\
│  │  ├─ SafeHouseAccessMod\
│  │  ├─ NoSuchPlace_GrenadeDoor\
│  │  └─ NoSuchPlace_ItemLabel\
│  ├─ config\                       ← 各 MOD 的 .cfg
│  └─ LogOutput.log                 ← 插件加载与报错日志
└─ .nosuchplace\                    ← 部署器状态、备份与日志
```

配置文件命名规则：`<插件 GUID>.cfg`。例如 `com.mod.affixselector.cfg`、`com.deepseek.nosuchplace.customweight.cfg`。

## 六、常见问题

**Q：双击 exe 弹出「未知发布者 / Windows 已保护你的电脑」怎么办？**
A：这是 Windows 的 SmartScreen 对「来自网络」文件的拦截，不代表文件有问题。右键 exe → 属性 → 勾选「解除锁定」→ 确定，再运行。通过浏览器或网盘重新下载后标记会重新出现，需要再解一次。

**Q：提示找不到游戏 / 检测不到前置？**
A：一是目录层级选错，应选含 `NoSuchPlace.exe` 的目录；二是确实没装过前置，此时按提示选择 BepInEx 5 或 6。

**Q：部署时报「游戏正在运行」？**
A：部署器会拒绝在游戏运行时写文件。请完全退出游戏（含后台进程）后重试。

**Q：MOD 显示「同版本」，但我想要它写入新的 DLL？**
A：部署器按版本号判断。若包内版本号未变，状态就是「同版本」且默认不勾选。需要覆盖时手动勾选该行再部署。若希望默认覆盖，应由 MOD 提升版本号后重新打包。

**Q：切换前置栈后 MOD 全部变红了？**
A：正常。MOD 与前置栈绑定，切栈必须整套重装，界面会默认全选并提示。

**Q：装完进游戏没变化？**
A：依次检查：游戏是否完全重启（插件只在启动时加载）；`BepInEx\LogOutput.log` 是否有该插件 loaded 记录与报错；前置是否为 5/6 对应版本；是否部署了正确栈。

**Q：怎么确认部署了哪些文件、什么时候装的？**
A：看 `.nosuchplace\state.json`（栈、版本、文件清单）与 `.nosuchplace\logs\`。

**Q：装错了怎么退回？**
A：命令行运行 `--rollback`，会还原最近一次备份，并删除本次新建的文件与空目录。

**Q：应愿粉尘去哪拿？**
A：两种方式：制作台（General 工作台）制作，或在黑市购买（单价 50000）。若黑市里看不到，检查「仅官方物品」开关与是否重进过黑市；若制作台没有配方，查看日志是否有 `[AffixSelector]` 的注入记录或 `WishDust injection FAILED`。

**Q：调校终端里「更多自定义配置」显示成一堆通用参数行？**
A：说明扩展页不可用（扩展 DLL 缺失或协议版本不匹配）。日志会提示一次并回退通用参数行；通用参数行仍可修改全部配置，不影响功能。

**Q：黑市打开很卡？**
A：保持分页开启（默认每页 20 件），或适当调小每页数量；关闭分页会一次性渲染全部商品。

**Q：MOD 配置在哪里改？**
A：三种途径：游戏内 MOD 调校终端（F7）；各 MOD 自带面板（如 F5、F6）；直接编辑 `BepInEx\config\<GUID>.cfg`（改完需重启游戏）。

**Q：支持联机吗？**
A：整合包本身不做联机同步；数值类 MOD（负重、移速、经验、等级上限）与物品/掉落相关调整在联机时可能只影响本地表现，具体以实际测试为准。

## 七、术语

- 前置 / 栈：BepInEx。5 与 6 是两条独立技术栈，插件不能跨栈混用。
- 插件 GUID：插件唯一标识，决定 cfg 文件名与配置归属。
- 增量部署：按 SHA256 比对，只写有差异的文件。
- 同版本：已装版本与包内版本号相同。
- 专用页：调校终端里由扩展 DLL 提供的结构化配置界面。
- MOTW：Windows 对网络来源文件打的标记，触发 SmartScreen。
